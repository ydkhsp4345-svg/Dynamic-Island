# AdaIsland – Android Dynamic Island

## APK'yı bilgisayarsız derleme (GitHub Actions)
1. github.com'da ücretsiz hesap aç, yeni bir repo oluştur.
2. Bu zip'in içindeki dosyaları klasör yapısıyla birlikte repoya yükle
   (.github/workflows/build.yml dosyası dahil).
3. Repo > Actions > "Build APK" > Run workflow.
4. İş bitince "Artifacts" bölümünden AdaIsland-apk dosyasını indir, telefona kur.

## Kurulumdan sonra
1. Uygulamayı aç, 1-2-3 numaralı izin butonlarına sırayla dokun.
2. "Adayı başlat"a bas. Adaya uzun basınca ayarlar açılır.
